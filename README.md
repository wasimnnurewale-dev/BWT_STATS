# Statistics Assignment

A starter Python project for exploring a dataset with descriptive statistics.

## What is included

- Mean, median, mode, range, variance, and standard deviation
- Quartiles and interquartile range
- A five-number summary
- A small sample dataset that can be replaced with assignment data

## Requirements

- Python 3.9 or newer

## Run the analysis

```powershell
python statistics_analysis.py
```

To use another dataset, edit the `data` list in `statistics_analysis.py`.
